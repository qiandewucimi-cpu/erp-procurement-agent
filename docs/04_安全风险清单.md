# 04 安全风险清单

| 风险 | 控制措施 | 验证证据 | 剩余风险 |
|---|---|---|---|
| 提示注入诱导写入 | policy_guard 只信任工具返回的 action_id；确认须精确口令 | 模型对抗评测 | 模型仍可能产生误导性文字，UI 应明确工具结果优先 |
| 身份伪造 | Token/open_id/MCP 身份在入口绑定；忽略模型 operator 参数 | 权限单测 | Demo Token 映射不替代企业 IAM |
| 越权与自审 | viewer/operator/approver 权限矩阵；Repository 再校验自审 | API 与状态机测试 | 角色配置错误仍需运维治理 |
| 重复/并发写入 | action_id、唯一约束、事务写锁、幂等响应 | 四线程并发评测 | 多实例需共享幂等存储与分布式协调 |
| 错误金额 | 价格和包装费由档案查询，确定性代码计算 | 金额断言 | 上游主数据错误仍需人工复核 |
| BOM 路径穿越 | 仅解析 samples/uploads 白名单和允许后缀 | 输入安全评测 | 上传文件仍需生产级病毒与内容扫描 |
| ERP 服务故障 | 超时、有限指数退避、稳定异常映射 | Adapter 故障测试 | 重试策略需按客户限流规则调整 |
| 密钥泄露 | `.env`/日志/数据库忽略；结构化日志递归脱敏 | 镜像扫描与脱敏测试 | 人工截图、终端粘贴仍可能泄露 |
| 审计缺失 | 状态变更记录 actor、action 和事件 | 审计链测试 | 生产需不可篡改日志与保留策略 |
| 数据越界发布 | 公开版只含合成数据；同步前敏感扫描 | S8 验收 | 新增材料必须继续人工复核 |

## 上线前强制门槛

客户生产前必须完成真实接口契约确认、沙箱联调、SSO/IAM、密钥托管、上传安全、集中审计、监控告警、备份恢复、权限评审和回滚演练。本仓库当前不满足生产上线声明。

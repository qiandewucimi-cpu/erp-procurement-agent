# 06 部署运行手册

## 本地演示

1. Windows 双击 `start_demo.cmd`，或执行 `start_demo.ps1`。
2. 打开 `http://127.0.0.1:8501`；API 文档为 `http://127.0.0.1:8000/docs`。
3. 不配置模型时，确定性 `/agent/prepare` 仍可运行；对话工具循环需要支持 Function Calling 的模型。

## 配置

复制 `.env.example` 为 `.env`。默认 `ERP_BACKEND=sqlite`，只使用合成数据。客户测试 API 联调时才设置 `ERP_BACKEND=http`、API 地址与 Token。开启 `ERP_AUTH_ENABLED=true` 后配置随机 Token 与 viewer/operator/approver 身份映射。

`.env` 不得提交、复制到文档或打进镜像。修改配置后重启进程。

## Docker

```powershell
docker compose build
docker compose up -d
docker compose ps
```

API 数据保存到命名卷 `erp_demo_data`，上传目录挂载为 `./uploads`。停止服务使用 `docker compose down`；不要在需要保留数据时加 `-v`。

## 启动后检查

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
Invoke-RestMethod http://127.0.0.1:8000/metrics
```

应确认 `status=ok`、`production_connected=false`，再执行正常和异常 BOM 演示。RBAC 开启时请求必须带 `Authorization: Bearer <token>`，不要把真实 Token 写进命令历史截图。

## 发布边界

公开仓库只发布合成数据和 `.env.example`。客户测试部署需另行完成网络、TLS、密钥托管、日志保留、备份与访问控制评审。

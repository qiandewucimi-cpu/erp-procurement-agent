# 简历项目表述 v0.6

> 适用于 AI 交付工程师（FDE）/ AI 解决方案岗位。以下数字对应 2026-09-13 已验证基线；后续变化需同步更新。

### 外贸 ERP 采购流程助手　FastAPI / Function Calling / MCP / 飞书　2026.08 – 至今

- 基于实习中的 BOM→采购 PO 流程抽象，以合成数据构建可运行原型；解析 Excel/CSV、检索业务规则并查询物料/价格，确定性计算金额和阻断异常，不连接生产 ERP。
- 设计受控工具调用 Agent：模型自主编排 8 个业务工具与多轮上下文；新增 SQLite/HTTP 可替换 ERP Adapter，覆盖 Bearer 鉴权、超时重试、稳定错误映射与幂等键。
- 建立 viewer/operator/approver RBAC 与职责分离状态机，叠加可信 action_id、精确确认口令、并发幂等、审计与回滚；40 条安全/能力评测最近一次 40/40，单测 93/93、覆盖率 90%。
- 通过 FastAPI、Streamlit、MCP 与飞书长连接交付同一业务能力；加入 request/session/action/tool 结构化日志和延迟指标，并沉淀需求、ADR、安全、验收、部署、排障及试点回滚文档。

## 口径说明

- “40/40”是一次明确记录的全量运行：25 条确定性场景 + 15 条真实模型场景；模型结果可能漂移。
- “93/93”是 S19 回归时的单元测试基线；“88/88”仅是 S5/S6 的历史基线。
- “覆盖率 90%”是 S19 最近一次测量值，不写成持续保证。
- 不使用“生产落地”“真实 ERP 上线”“企业级 IAM/监控”等未经验证表述。

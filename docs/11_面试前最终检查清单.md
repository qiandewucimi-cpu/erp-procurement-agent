- [ ] 准备无网络方案：`smoke_interview.py`、评测报告、架构图和截图。

## 不可恢复时的降级

- 模型不可用：明确说明当前为确定性聊天降级，演示草稿/确认安全链路；同时运行离线烟测并展示最近一次真实模型评测报告，不把降级模式描述成 Agent 自主编排。
- UI 不可用：用 FastAPI 文档或测试输出展示工具与状态机。
- 网络不可用：不临时改依赖，使用本地架构图、截图、报告和 Git 历史。
- 新缺陷出现：不掩盖，记录复现条件、影响、安全兜底和下一步修复。

## 冻结规则

公开 main CI 全绿后记录 commit 与 run id；面试前只接受阻断级修复。任何功能改动都重新执行预检，任何公开发布都再次做脱敏扫描。真实业务材料、个人简历全文和 `.env` 永不提交公开仓库。

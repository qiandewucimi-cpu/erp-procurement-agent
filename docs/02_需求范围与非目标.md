# 02 需求范围与非目标

## 第一阶段范围

- 解析白名单目录中的 Excel/CSV BOM 与物料档案。
- 检索采购规则，查询合成物料主数据，生成并校验采购 PO 草稿。
- 通过 Function Calling 编排 8 个工具，并展示工具轨迹和规则来源。
- 写前预览、RBAC、职责分离审批、精确确认口令、幂等、审计与回滚。
- SQLite Demo Adapter 与可测试的 HTTP ERP Adapter。
- Web、REST、MCP、飞书四种入口共享同一业务和安全边界。
- 40 条能力/安全评测、单元测试、结构化日志和进程内指标。
- Windows 与 Docker 本地交付。

## 明确非目标

- 不连接或模拟声称连接了真实企业生产 ERP。
- 不使用真实客户、合同、价格、账号或内部文档。
- 不让模型直接执行 SQL、计算最终金额或绕过审批写入。
- 不实现通用 ERP 的全部采购、库存、财务功能。
- 不将 Demo Token 映射包装为企业级 SSO/OAuth/IAM。
- 不将进程内会话、指标或 SQLite 包装为生产级高可用方案。
- 不在未经客户接口契约、沙箱验证和安全评审时进入生产。

## 验收边界

“第一阶段完成”指仓库内合成场景可复现、测试证据可追溯、面试材料与实现一致；不等同于客户生产验收。公开发布前还需完成脱敏扫描与公开镜像回归。

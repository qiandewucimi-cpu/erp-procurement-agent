# 采购流程执行回放

![64 秒执行回放](execution-replay.gif)

此动画将 `capture_demo.py` 实际执行结果排成八帧，每帧8秒。它不是聊天界面录屏，也不验证模型规划能力。运行日期为2026-10-21（北京时间），仅使用仓库合成数据与临时 SQLite。

复现命令（仓库根目录、已安装依赖）：

```bash
python capture_demo.py --output docs/demo/trace.json
```

脚本主动启用角色校验，依次验证：

1. 正常 BOM：3行，金额 ¥24,164，生成草稿。
2. viewer 建单被拒绝。
3. 异常 BOM 被阻断。
4. 独立审批人批准正常草稿。
5. 使用精确口令确认提交。
6. 重复确认返回同一单据。
7. 核对最终单据数量与审计记录。

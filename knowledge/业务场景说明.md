# BOM 到采购 PO 业务场景（合成演示版）

## 业务痛点

录单人员通常需要在 BOM、价格资料、包装费资料、原始 PO 和 ERP 页面之间切换。人工跨表搬运会产生漏填、错填和重复等待，字段规则不清楚时还需要翻培训资料或询问同事。

## Agent 目标

用户上传 BOM 并提出“生成采购 PO”后，Agent 先查操作规则，再解析 BOM，随后调用模拟 ERP 查询物料、供应商、价格和包装费，生成可解释的采购 PO 草稿。每行结果保留数据来源，异常字段明确指出原因。

## 人机协作边界

Agent 负责查找、取数、计算、校验和生成草稿；人负责确认业务意图和最终提交。涉及生产系统时还应增加真实身份认证、角色权限、审批流、密钥管理和监控，本 Demo 不连接任何生产系统。

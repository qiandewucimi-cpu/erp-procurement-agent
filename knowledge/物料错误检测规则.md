# 物料错误检测规则（合成演示版）

> 本文仅用于个人作品演示，不来自任何企业生产数据。

## 检测范围

录单员上传 BOM 后，Agent 对每一行物料逐项校验，发现错误时分级汇总成报告，可推送给录单员处理。

## 错误分级

- **阻断（blocking）**：会导致无法正确生成采购单，必须修正才能继续。
- **警告（warning）**：不影响生成，但需留意，以档案为准或需人工确认。

## 错误类型

| 类型 | 级别 | 触发条件 |
|---|---|---|
| 编码为空 | 阻断 | 物料编码缺失 |
| 数量非法 | 阻断 | 数量缺失、非数字或小于等于 0 |
| 未建档 | 阻断 | 物料编码在 ERP 物料档案中不存在 |
| 名称不一致 | 警告 | BOM 名称与档案名称不同，以档案为准 |
| 单价缺失 | 阻断 | 采购单价缺失或非正数 |
| 包装费缺失 | 警告 | 包装费缺失 |
| 供应商缺失 | 阻断 | 供应商编码或名称缺失 |

## 报告与推送

检测默认只读、不写库；只有明确要求推送时，才把错误报告写入推送队列（error_reports），并记录审计日志。报告按错误类型聚合计数，同时生成一段可直接发给录单员的文本。

## 安全边界

检测、分级和汇总全部由确定性代码完成，模型只负责理解用户意图和决定是否推送，不参与错误判断。
